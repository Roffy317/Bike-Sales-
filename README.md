# Bike Sales Analysis (Excel)

## Project Overview
This project analyses bike sales data using Microsoft Excel to understand customer purchasing behaviour and identify factors influencing bike purchases.

## Key Analysis
- Average income per bike purchase
- Bike purchases by age group
- Bike purchases by commute distance
- Customer demographics by region, gender and marital status

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- PivotTables
- PivotCharts
- Interactive Dashboard
  

## Objective
To identify customer purchasing patterns and generate insights that can help improve marketing and sales strategies.
